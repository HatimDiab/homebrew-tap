# HatimDiab Tap

## How do I install these formulae?

`brew install hatimdiab/tap/<formula>`

Or `brew tap hatimdiab/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "hatimdiab/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
